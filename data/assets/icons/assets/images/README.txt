Папка для изображений православных икон.

Размещайте здесь изображения, которые разрешено использовать и распространять.

Форматы: JPG, JPEG, PNG, WEBP.

Названия файлов желательно писать латиницей без пробелов.

Пример:
nikolay-chudotvorets.jpg
matrona-moskovskaya.jpg
sergiy-radonezhskiy.jpg
mother-of-god-kazan.jpg

Пути к изображениям указывайте в данных библиотеки.
