# Православный календарь 2027–2028 — расширенная сборка

Статическое приложение для GitHub Pages. Интерфейс и встроенная база доступны без сети после первого открытия. Дополнительный календарный массив за оба года можно загрузить кнопкой «Загрузить полный месяцеслов»; он сохраняется в IndexedDB этого браузера и затем доступен офлайн.

## Важно о полноте и церковной точности

В архив включены 731 календарных дат, вычисляемый пасхальный цикл, основные неподвижные праздники, постные периоды и 51 справочная карточка святых. Это расширенная автономная основа, но **не полный официальный месяцеслов Русской Православной Церкви**. Полный перечень всех местночтимых святых, уставные указания, чтения, изменяемые песнопения и послабления поста нельзя добросовестно объявить полными без сверки с утверждённым календарём конкретной церковной юрисдикции.

Кнопка синхронизации обращается к публичному API `api.ispovednik.org`. Документация указывает, что календарь API основан на календаре РПЦЗ в редакции, известной до разделения 2007 года. Это дополнительный справочник, а не официальный календарь Московского Патриархата. Данные API не смешиваются молча с исходной базой: после загрузки они используются как расширение и сохраняются локально. Перед богослужебным применением сверяйте данные с календарём своего прихода/епархии.

Пасха: 2 мая 2027 года и 16 апреля 2028 года. Основные подвижные даты сверены по OCA и Greek Orthodox Archdiocese of America; календарные различия традиций возможны.

## Установка на GitHub Pages — подробно

### 1. Скачать и распаковать

1. Скачайте ZIP-архив.
2. На компьютере распакуйте его в отдельную папку. На iPhone: откройте ZIP в приложении «Файлы» — iOS создаст папку с содержимым архива.
3. Внутри должна быть папка проекта с `index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest` и каталогом `data`. **Загружать нужно содержимое папки проекта, а не ZIP-файл.**

### 2. Создать репозиторий

1. Откройте https://github.com и войдите в аккаунт.
2. Нажмите `+` вверху справа → `New repository`.
3. Введите имя, например `pravoslavny-calendar`.
4. Выберите `Public` (GitHub Pages на бесплатном тарифе проще использовать с публичным репозиторием).
5. Не ставьте галочку `Add a README file`, если загружаете готовый README из архива.
6. Нажмите `Create repository`.

### 3. Загрузить файлы

1. В репозитории нажмите `Add file` → `Upload files`.
2. Откройте распакованную папку проекта и выделите **все файлы и папки внутри неё**.
3. Перетащите их в окно загрузки GitHub. На телефоне используйте `choose your files` и выберите элементы из приложения «Файлы»; если мобильный браузер не позволяет выбрать папку целиком, удобнее выполнить загрузку с компьютера.
4. Убедитесь, что `index.html` виден в корне репозитория, а не внутри дополнительной вложенной папки.
5. Внизу страницы в поле commit message напишите `Add Orthodox calendar app` и нажмите `Commit changes`.

### 4. Включить GitHub Pages

1. Откройте вкладку `Settings` репозитория.
2. В боковом меню найдите `Pages`.
3. В блоке `Build and deployment` в поле `Source` выберите `Deploy from a branch`.
4. В поле `Branch` выберите `main`; рядом выберите папку `/ (root)`.
5. Нажмите `Save`.
6. Подождите 1–5 минут и обновите страницу `Settings → Pages`. GitHub покажет адрес сайта вида `https://ВАШ-ЛОГИН.github.io/pravoslavny-calendar/`.
7. Откройте адрес. Если сайт не появился сразу, подождите ещё несколько минут и проверьте вкладку `Actions` — там отображается статус публикации.

### 5. Первый запуск и офлайн-режим

1. Откройте опубликованный сайт при подключённом интернете.
2. Дождитесь загрузки страницы, затем обновите её один раз. Браузер установит Service Worker и закеширует основные файлы.
3. Нажмите `Загрузить полный месяцеслов`. Дождитесь сообщения об успешной синхронизации за 2027 и 2028 годы.
4. После этого календарные данные будут сохранены в IndexedDB этого браузера. Отключите интернет и проверьте повторное открытие сайта.
5. Офлайн-доступ действует на том устройстве и в том браузере, где сайт уже был открыт и синхронизирован. В приватном режиме и после очистки данных браузера кэш может исчезнуть.

### 6. Как обновить сайт после изменений

1. Откройте репозиторий → `Add file` → `Upload files`.
2. Загрузите изменённые файлы с теми же путями, подтвердите `Commit changes`.
3. Если браузер продолжает показывать старую версию, закройте вкладку, откройте сайт заново или очистите данные сайта. Service Worker может хранить предыдущую версию до обновления кэша.

## Что есть в проекте

- `index.html` — интерфейс;
- `styles.css` — адаптивное оформление;
- `app.js` — календарь, поиск, карточки, избранное, синхронизация;
- `data/calendar-base.json` — 731 дат с локальными справочными отметками;
- `data/saints.json` — 51 карточка святых;
- `data/library.json` — подборки молитв, акафистов, песнопений и указатели;
- `data/calendar-notes.json` — пасхальный цикл и постные периоды;
- `sw.js` — офлайн-кэш;
- `manifest.webmanifest` — параметры установки приложения.

## Тексты, Библия, аудио и иконы

Встроенный каталог содержит молитвенные тексты и справочные карточки, но не полные тексты всех акафистов, канонов и всей Библии. Это сознательно: редакции богослужебных текстов и переводы Писания могут быть защищены авторским правом и должны сверяться с церковными изданиями.

Локальные материалы добавляйте в `assets/audio/`, `assets/images/` и `data/scripture/`. Для каждого файла добавляйте в JSON относительный путь и сведения об источнике/разрешении. Внешние ссылки на сайты не гарантируют воспроизведение офлайн. Не загружайте чужие аудиозаписи, фотографии и переводы без разрешения.

## Источники

- https://api.ispovednik.org/docs/en/ — API календаря, памяти святых и поста; в документации указана традиция РПЦЗ;

- https://www.goarch.org/chapel/paschalion?year=2027 — подвижные праздники;

- https://azbyka.ru/akafistnik/ — каталог акафистов;
- https://azbyka.ru/audio/ — каталог православного аудио.

Приложение справочное и не заменяет богослужебный календарь, молитвослов, благословение духовника или указания прихода.
